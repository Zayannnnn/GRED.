## 🚀 Local Development Setup & Live Server

Web3Forms supports static sites and GitHub Pages, but direct `file:///` browsing may still prevent form submissions during development. Using a local web server such as VS Code Live Server is recommended for accurate testing.

### VS Code "Live Server" Configuration (Recommended)
To run the website in a proper local server environment:

1. **Install Live Server Extension:**
   - Open VS Code.
   - Go to Extensions (`Ctrl+Shift+X` or `Cmd+Shift+X`).
   - Search for **"Live Server"** (by Ritwick Dey) and click **Install**.

2. **Launch GRED Local Host:**
   - Open GRED's root folder in VS Code.
   - Right-click on [index.html](file:///Users/favasev/Desktop/GRED.-main/index.html) in the file explorer.
   - Select **"Open with Live Server"** (or click the **Go Live** button in the bottom status bar).

3. **Access GRED:**
   - The browser will automatically open:
     `http://localhost:5500/` or `http://127.0.0.1:5500/`
   - You can now navigate to **Invest In Us** and test form submissions.
